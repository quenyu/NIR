# Запуск на Windows

## Быстрый запуск

1. Полностью распакуйте ZIP-архив в обычную папку.
2. Запустите `start_windows.bat`.
3. Дождитесь открытия двух служебных окон и страницы `http://127.0.0.1:5173`.
4. Не закрывайте окна backend и frontend во время работы.

Node.js для готового архива не требуется: frontend уже собран и раздаётся встроенным сервером Python.

## Требования

- Windows x64;
- Python 3.13 x64;
- около 250 МБ свободного места для локального кэша зависимостей.

Если подходящий Python не найден, запускатель предложит установить его через `winget`. При отсутствии `winget` установите Python 3.13 x64 с официального сайта и повторите запуск.

## Что делает запускатель

- выбирает 64-разрядный Python 3.13;
- копирует вложенные зависимости в `%LOCALAPPDATA%\ControlLab`;
- проверяет FastAPI, Uvicorn, NumPy, SciPy и Pydantic;
- запускает backend на `http://127.0.0.1:8000`;
- запускает frontend на `http://127.0.0.1:5173`.

Локальный кэш создаётся один раз и затем используется повторно.

## Возможные проблемы

Ошибка `%1 is not a valid Win32 application` обычно означает несовпадение архитектуры Python, повреждение DLL или отсутствие Visual C++ Runtime. Убедитесь, что установлен Python 3.13 x64. При необходимости установите [Microsoft Visual C++ Redistributable x64](https://aka.ms/vc14/vc_redist.x64.exe), удалите `%LOCALAPPDATA%\ControlLab` и снова запустите `start_windows.bat`.

Если порт 5173 или 8000 занят, завершите старый экземпляр приложения и повторите запуск.
